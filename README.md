A one-line excuse, in the GPS's own voice, for sending the driver down the wrong road: the map promised a shortcut through a cul-de-sac, the GPS believed it, and now insists the lake at the end beats wherever the driver was going. Run `node main.ts` and it writes the line to `/output/entry.txt`.
